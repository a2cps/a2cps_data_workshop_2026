# A2CPS Data Workshop 2026

Website for **Exploring the A2CPS Multimodal Data Resource**, a virtual workshop on the
Acute to Chronic Pain Signatures (A2CPS) dataset. Tuesday, September 29, 2026, 1:00–2:30 pm ET.

Find the live site at: 
https://a2cps.github.io/a2cps_data_workshop_2026

Static site, no build step. Serve the folder or enable GitHub Pages (Settings → Pages → deploy from `main`, root).

| Page | File |
|---|---|
| Home (hero, highlights, schedule at a glance, data types, outline) | `index.html` |
| Schedule (full agenda and speakers) | `schedule.html` |
| The Study (cohort, data types, timeline, biomarkers, releases, consortium) | `study.html` |
| Resources (NDA access, starter kits, docs, videos, papers, citation) | `resources.html` |

Shared assets live in `assets/`: `css/site.css` (design tokens, light and dark themes),
`js/hero.js` (interactive logo and particle trail), `js/site.js` (nav, reveal animations),
`a2cps-data-workshop-2026.ics` (calendar file), and images.
